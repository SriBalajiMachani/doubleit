## Project Description
"Double It" Recipe Book Goal: Make a button change numbers on the screen. • Page 1 (Menu): Show pictures of 2 meals (e.g., Cake and Pizza). Click one to go to Page 2. • Page 2 (Recipe): List the ingredients for 1 person (e.g., 2 eggs, 1 cup flour). Add a button that says "Double Recipe". • JavaScript: When the user clicks "Double Recipe", change the text on the screen so all the numbers multiply by 2 (e.g., changes to 4 eggs, 2 cups flour).
---

## Project Objective

The goal of this project is to build an interactive two-page recipe book where a button dynamically changes the numbers on the screen:

- **Page 1 (Menu):** Displays 2 signature meals (Olive Oil Cake & Burrata Pizza). Clicking either dish opens its recipe.
- **Page 2 (Recipe):** Lists the ingredients for 1 person (e.g., 2 eggs, 1 cup flour).
- **"Double Recipe" Button:** When clicked, JavaScript dynamically multiplies every ingredient quantity by 2 (e.g., 2 eggs $\to$ 4 eggs, 1 cup flour $\to$ 2 cups flour).
- **Reset Button:** Restores ingredient amounts back to the original 1-person portion.
